Import lịch sử báo giá

Excel → Firestore/LichSuBaoGia

Chức năng riêng biệt: chọn file danh sách VCX để preview và cập nhật trực tiếp các hồ sơ đã có trong Firestore, không cần file dữ liệu tổng hợp.

Khóa chống trùng khi import dữ liệu tổng hợp: so_hsbt + ten_phu_tung.

Import/Cập nhật VCX riêng biệt: chọn file VCX độc lập. Nếu file có đủ Số HSBT + Tên phụ tùng, hệ thống giữ nguyên từng dòng và cập nhật theo key so_hsbt + ten_phu_tung. Nếu file chỉ có danh sách Số HSBT, hệ thống chỉ cập nhật nhãn VCX cho dữ liệu đã có.

Import tổng hợp: nếu chọn cả file dữ liệu tổng hợp + file VCX, dòng có Số HSBT nằm trong file VCX sẽ được gắn VCX, dòng còn lại trong file tổng hợp gắn TNDS.

Cột bắt buộc của file tổng hợp: Số HSBT, Tên phụ tùng, Hãng xe, Hiệu xe/Dòng xe, Chính hãng/Loại hàng, Duyệt - Tiền phụ tùng/Giá duyệt, Ngày báo giá, Tên Garage.

Cấu hình OCR báo giá
AI OCR Provider
Chọn engine xử lý báo giá. Gemini đọc trực tiếp ảnh/PDF và bóc JSON. OCR.Space dùng API OCR miễn phí để lấy text, sau đó hệ thống tự tách bảng báo giá thành dòng phụ tùng để bạn kiểm tra/chỉnh lại trước khi tra kho. API key được lưu riêng theo từng tài khoản trong Firestore collection user_api_keys, không dùng chung giữa các user.
Đang đọc cấu hình từ Firestore theo tài khoản hiện tại.
